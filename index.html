PriVideo — quick start

Import video, audio and images with the Import button (or drag files into the app). Double-click an asset to add it to a track, or drag it directly onto the timeline. Drag clips to move them, drag their ends to trim, and use the razor to split.

Record audio: Click Record audio in Project media, choose your microphone/audio interface or a shared computer-audio source, set the start time, then record. Stop & keep places the WAV on a free audio track. Download the take or save a local session before closing; project JSON does not contain audio bytes. Five-minute limit per take. Use headphones. Computer/tab audio is offered only where the browser and operating system support it.

Playback output: In the lower Sequence bar click Output, or in Record audio click Choose / test. Pick your speakers or headphones, play the two-note test tone, then select I heard it to confirm. This changes monitor, timeline and take-preview listening, never the microphone input or downloaded audio. In browsers without output-device permission, change your operating-system sound output.

Text: Click Add text (T), type on the monitor and choose Done. Drag the text box to move it; drag its corner to resize. The Text studio has font, colour, bold, italic, underline, alignment, outline, background, presets and timing. Fonts shows whether each requested face is really available. Lato loads online; the other fonts use installed or user-supplied licensed files. Text uses the same renderer in preview and export.

Direct editing: Click footage in the monitor, then drag it to reposition. Drag its corner handles, use the +/- buttons or scroll over it to change clip zoom; these changes appear in exports. Fit/Fill centres the image. Double-click footage or an audio clip for Speed & duration. Double-click text to edit it. Double-click an empty timeline gap to close it. Ripple deletion affects the clicked/selected track only; other tracks, separate voiceovers, captions on other tracks and markers remain unchanged. Cmd/Ctrl+Z undoes each edit.

Captions: Open the Captions tab to type subtitles, import .srt/.vtt, or try free on-device automatic speech recognition (Whisper Tiny English). Caption generation needs a model download, enough available RAM, and a compatible browser. Check the output before sharing.

Projects: Save and open editable project files. To keep project files small, they store edit decisions rather than embedding multi-GB videos. After reopening, re-import the matching original media filenames to relink them. Edit decisions are autosaved locally. The recovery prompt restores them after refresh; re-import originals to relink. Save local session explicitly stores media in IndexedDB, without uploading it. Browser storage may be evicted, so keep a downloaded project backup.

Limitations: This is not Adobe Premiere Pro and doesn't include all of its effects, codecs, collaborative services, or native GPU render pipeline. Export depends on browser memory, device speed, and the codec support built into FFmpeg.wasm. Chrome/Edge desktop recommended. First export, auto-captions and conversion of unsupported MP4/MOV codecs need internet to download open-source dependencies. PriVideo automatically makes a lower-resolution, browser-playable H.264 preview of unsupported footage, while keeping the original for rendering.

Engine diagnostics

Exports automatically test the real engine first: 200 fps MP4, fractional-rate WebM, short chunks, final frames and audio samples. Run again here at any time.

Diagnostic downloads exclude video bytes and redact imported filenames. Review the file before sharing. Reset cancels active work without deleting the timeline.

Text fonts
Lato loads from an open-source web font service. Helvetica, Times New Roman and Arial use your installed fonts. A website cannot install system fonts; missing fonts are shown honestly and are not silently substituted in exports.
Imported fonts remain on your device and are not included in project downloads. Only load files you are entitled to use. A regular-only file can be styled with browser-synthesised bold/italic.
