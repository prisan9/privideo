PriVideo — quick start

Import video, audio and images with the Import button (or drag files into the app). Double-click an asset to add it to a track, or drag it directly onto the timeline. Drag clips to move them, drag their ends to trim, and use the razor to split.

Captions: Open the Captions tab to type subtitles, import .srt/.vtt, or try free on-device automatic speech recognition (Whisper Tiny English). Caption generation needs a model download, enough available RAM, and a compatible browser. Check the output before sharing.

Projects: Save and open editable project files. To keep project files small, they store edit decisions rather than embedding multi-GB videos. After reopening, re-import the matching original media filenames to relink them. Edit decisions are autosaved locally. The recovery prompt restores them after refresh; re-import originals to relink. Save local session explicitly stores media in IndexedDB, without uploading it. Browser storage may be evicted, so keep a downloaded project backup.

Limitations: This is not Adobe Premiere Pro and doesn't include all of its effects, codecs, collaborative services, or native GPU render pipeline. Export depends on browser memory, device speed, and the codec support built into FFmpeg.wasm. Chrome/Edge desktop recommended. First export, auto-captions and conversion of unsupported MP4/MOV codecs need internet to download open-source dependencies. PriVideo automatically makes a lower-resolution, browser-playable H.264 preview of unsupported footage, while keeping the original for rendering.

Engine diagnostics

Exports automatically test the real engine first: 200 fps MP4, fractional-rate WebM, short chunks, final frames and audio samples. Run again here at any time.

Diagnostic downloads exclude video bytes and redact imported filenames. Review the file before sharing. Reset cancels active work without deleting the timeline.
